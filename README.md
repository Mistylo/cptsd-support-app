# CPTSD Support App

A trauma-informed mobile application prototype designed to provide self-help and emotional support for individuals living with Complex Post-Traumatic Stress Disorder (cPTSD).

This project was developed as part of my MSc project at the University of Galway. The application explores how evidence based therapeutic approaches, particularly STAIR and CBT, can be translated into accessible digital tools while considering emotional safety, privacy, personalisation, and user autonomy.

## Features

The current prototype includes:

- **SOS Protocol** for users experiencing flashbacks or acute emotional distress
- **Grounding Tools**, including 5-4-3-2-1 grounding
- **Guided Breathing and Meditation**
- **Emotional Awareness and Mood Tracking**
- **Journaling**
- **Thought Reframing** with AI-assisted support
- **Interpersonal Skills** activities
- **Psychoeducation** about cPTSD and emotional regulation
- **Personalisation**, including themes, layouts, tool settings, and custom icons
- **Sticker-based Progress System**
- **Local Data Storage**
- **Google Drive Backup and Data Export/Import**
- **PIN-based App Lock**
- **Affirmation Notifications**
- **Onboarding guides** for the main application sections

## Technology

The application was developed using:

- **Flutter / Dart** – mobile application development
- **Riverpod** – state management
- **Isar** – local database
- **Flutter Secure Storage** – secure storage for sensitive information
- **Dio** – HTTP requests
- **Claude API** – AI-assisted features
- **Google Drive API** – optional user-controlled cloud backup

## Project Approach

The application was developed through an iterative process combining:

1. Literature review
2. Comparative analysis of existing digital mental health applications
3. User interviews and feedback
4. Requirement development
5. Trauma-informed design and prototyping
6. Iterative implementation and testing

The design was informed by STAIR, CBT, trauma-informed design principles, and findings from user research.

## Privacy and Safety

The application follows a **local-first approach**, with core user-generated data stored locally on the device. Cloud backup is optional and controlled by the user.

AI features are designed as supplementary support and are **not intended to replace professional mental health care, diagnosis, or emergency services**.

This project is a research prototype and has not been clinically validated.

## Project Status

This project is currently a **student research prototype** developed for academic purposes. It demonstrates the design and technical feasibility of a trauma-informed digital intervention rather than a clinically approved treatment application.
